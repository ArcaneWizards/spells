# `@arcanewizards/spell`

[![](https://img.shields.io/npm/v/@arcanewizards/spell)](https://www.npmjs.com/package/@arcanewizards/spell)

<p align="center">
  <img src="https://raw.githubusercontent.com/ArcaneWizards/spells/refs/heads/main/packages/spell-assets/assets/icon.svg" height="150" width="150" alt="Timecode Toolbox Icon"/>

Arcane Spell Files are an open-source file-format that details precise timing
information of musical tracks,
for usage in lighting & visual applications for live events,
video rendering, pyrotechnics, etc...

They are the primary file format of the
[Arcane Desktop](https://arcanewizards.com/arcane) application,
and allow for quick exchange and sharing of timing information,
without the need to share full showfiles.

This package contains the type definitions and numerous parsing and utility
functions in TypeScript for this format.

## [Usage & Docs](https://github.com/ArcaneWizards/spells)

For full documentation on how to use this format,
please see the
[ArcaneWizards/spells repository on GitHub](https://github.com/ArcaneWizards/spells).
